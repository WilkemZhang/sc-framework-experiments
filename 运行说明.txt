第 7 节 · 随机测试函数、截取显示的下降图、最快方法表

在 PyCharm 打开包含 main.py 的文件夹，选择 Python 3.11 解释器（已在 3.11.5 验证）。在项目终端执行
    python -m pip install -r requirements.txt
运行 main.py，程序重做 980 次实验，输出四行两列、共用图例的八面板总图和一张最快方法表，同时保留八张独立下降图和四组双栏图。只需从随包提供的已有结果重画图表时直接运行 present.py。生成 PDF 图和表格的 LaTeX 源码无需安装 TeX。

目标与抽样
四族的变量都是 32 维。每族独立生成五个实例及相应的标准高斯起点；在同一实例上，七种方法和七档条件数均共用抽好的数据与起点。展示曲线固定使用第一组、条件档位 10⁶。
• Ridge。取 24×32 的矩阵 A，元素独立均匀分布于 [0,1]，独立从单位球内均匀抽 u，置 b=Au。目标是 ||Ax−b||²/(2n)+λ||x||²/2，n=24。u 是未正则化目标的一个解；正则化后的解由线性方程 (AᵀA+nλI)x*=Aᵀb 给出。曲率由抽到的 A 和正则强度决定。
• 非对称平方损失。抽一个标准高斯中心 b。对每个坐标的差 t=x_j−b_j，t≥0 时计入 κ_f t²/2，t<0 时计入 t²/2，各坐标求和。随机性平移了最优点和曲率切换的位置，两侧曲率固定为 1 和 κ_f。x*=b、f*=0。
• 二元 logistic。128×32 的 A 为独立标准高斯，对各行独立等概率抽 ±1。取二元 logistic 损失的平均，加 λ||x||²/2。
• Log-sum-exp。独立抽 128 个标准高斯斜率向量及 128 个标准高斯偏置，合成为单位温度的光滑最大值，加 λ||x||²/2。
有正则项的三族取 λ=C/(κ_f−1)。C 在 Ridge、logistic、log-sum-exp 中分别是 ||A||₂²/n、||A||₂²/(4n)、maxᵢⱼ||aᵢ−aⱼ||²/4。前两者与非对称平方损失的档位是精确全局条件数，log-sum-exp 为上界。

如何读图
从 k=0 出发，每接受一次更新就计一个迭代步。文件名以 _objective 结尾的单图画相对函数误差，以 _distance 结尾的单图画相对解距离平方；总图与双栏图则分别放在左、右两栏。非对称平方损失的解已知，两项误差可直接计算。Ridge 用线性方程得到数值参考点，另两类用独立的数值求解器。图中统一用 Δ_k/Δ_0 和 ||x_k−x*||²/||x_0−x*||²，其中 Δ_k=f(x_k)−f* 沿用前文定义。数值计算计入参考点残差：函数误差在可能的最优值区间内取最大值，距离误差在归一化前按参考点残差调整分子与分母。具体计算由 run.py 的 monitor 实现。
当最长曲线的实际停止迭代数超过第二长曲线的两倍时，两栏共用一个截止步数（第二长曲线停止步数的 105%，向上取整）。所有曲线均不加终点圆点或截断箭头。算法仍在两项误差于同一迭代首次均不超过 10⁻¹⁵ 时停止；图中保留实际误差值，不把终点移到阈值线上。完整轨迹保存在 results/curves.npz。全部图中，七个算法各用一种清晰的颜色：AdaNAG-G12 为深紫色，AdaNAG-G1/2 为深金色，AC-FGM 为绿色，AdaAGM5.5 为品红色，VC-FG 为亮蓝色，CC-FG 为鲜红色，NAG-SC 为深灰色。所有算法线宽相同，不加粗；VC-FG 和 CC-FG 使用实线并绘制在上层，其余算法使用虚线。图例采用相同的颜色和线型。
本轮四类函数的图窗截取情况（第一组）：
  Ridge 显示至 28,340 步，AdaNAG-G1/2 实际运行至 58,812 步。
  非对称平方损失显示至 4,712 步，NAG-SC oracle 实际运行至 27,135 步。
  二元 logistic 所有曲线均在 255 步内结束，全部显示。
  Log-sum-exp 显示至 323 步，NAG-SC oracle 实际运行至 4,387 步。

最快算法表
每个实例记录两项按上述方式计算的相对误差在同一个迭代步 k 首次同时达到 ε 的 k。每个方法对五个实例取中位数，再在七种方法之间选最小的中位数。正文每格显示“方法名（迭代数）”，凡并列均列。图窗截取不参与计算。7 档条件数 × 3 档精度 × 4 个目标，共 84 个排名结果。三个 ε 分别是 10⁻⁸、10⁻¹² 和 10⁻¹⁵。980 次实验均达到最后一档，最多用 59,688 步，预设预算为 150,000 步。
